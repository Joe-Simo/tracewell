## Title
Tracewell: design-control traceability for Jira and Confluence (Codegeist 2026, Atlassian Forge)

## Description
Tracewell is an Atlassian Forge app for teams that build regulated products, such as medical device software. It reads design-control traceability straight from Jira: user needs, design inputs and outputs, verification, validation, hazards and risk controls.

In this demo:
0:00 The problem: trace matrices in spreadsheets go stale when a requirement changes
0:20 Jira project page: coverage, gaps by type, trace matrix with CSV export, risk table
1:05 Issue panel: trace chain and change impact for a requirement
1:21 Suspect-link automation: a Forge trigger flags a passed test as suspect after its requirement changed
1:42 Forge log of a trigger run, release check, and a live run of the same actions the Rovo agent calls
2:16 Confluence trace report with page versions as the audit trail
2:34 Rovo agent, reusable skill and MCP server in the manifest
2:47 Project settings, 92 automated tests and the closing card

Built for Codegeist 2026 (Apps for Specialized Industries; Best Agents and Best app with Atlassian MCP bonus prizes).

Source: https://github.com/Joe-Simo/tracewell

Screens are real screenshots of the app running on a Jira and Confluence developer site with demo data. The narration is a synthetic voice (Piper TTS). Tracewell was built with AI-assisted development. Tracewell checks traceability; it does not certify compliance, and a quality reviewer still signs off.
